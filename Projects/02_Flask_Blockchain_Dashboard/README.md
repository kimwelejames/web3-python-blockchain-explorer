## Setup

Clone the repository:

```bash
git clone https://github.com/kimwelejames/web3-python-blockchain-explorer.git
cd Projects/02_Flask_Blockchain_Dashboard
```

Copy the example environment file:

```bash
cp .env.example .env
```

Edit `.env` and add:

- Your Alchemy API Key
- Your Etherscan API Key
- Your Wallet Address

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python run.py
```
